# 🌱 Hydrix — تطبيق المزرعة الذكية

تطبيق موبايل (PWA) يتسطب على التليفون كأي تطبيق عادي، ويتصل بـ **ESP32 عن طريق البلوتوث (BLE)** عشان يري النبات لما تدوس زرار.

> 📱 **التطبيق الحي:** https://mohamedebeid77.github.io/hydrix-smart-farm/
> افتح اللينك من موبايل أندرويد في Chrome → «إضافة إلى الشاشة الرئيسية» → خلاص اتسطب.

> 🎤 **عايز تجرب قدام اللجنة؟** افتح [DEMO.md](DEMO.md) — فيه تجربة كاملة قبل العرض + سيناريو 3 دقائق + حلول المشاكل الطارئة.

---

## 📱 تشغيل التطبيق على التليفون

Web Bluetooth (البلوتوث) بيشتغل بس في **Chrome على أندرويد** وعلى صفحة **HTTPS آمنة**. أسهل طريقة:

### الطريقة الأسهل — Netlify Drop (مجاني، في دقيقة)
1. افتح [https://app.netlify.com/drop](https://app.netlify.com/drop) من الكمبيوتر.
2. اسحب فولدر `hydrix` كامل على الصفحة.
3. هتاخد لينك HTTPS — افتحه من التليفون في Chrome.
4. من قائمة المتصفح اختَر **«إضافة إلى الشاشة الرئيسية»** → التطبيق اتسطب بأيقونة Hydrix زي أي تطبيق.

> تقدر كمان ترفعه على GitHub Pages بنفس الفكرة.

### تجربة على الكمبيوتر (وضع تجريبي بدون بلوتوث)
```bash
cd hydrix
python -m http.server 8080
```
وافتح `http://localhost:8080` في Chrome/Edge. التطبيق هيعمل في **وضع تجريبي**: الرطوبة تنزل مع الوقت، والري يرفعها، والري الذكي يشتغل بنفس المنطق — مثالي للعرض أمام اللجنة من غير عتاد.

> ✅ عايز APK حقيقي؟ استخدم [PWABuilder.com](https://www.pwabuilder.com): حط لينك التطبيق وحمّل ملف Android — ده بيطلع APK/TWA بمحرك Chrome فيعمل البلوتوث داخل التطبيق.

## 📡 ربط البلوتوث بـ ESP32

1. ارفع كود `esp32/hydrix_farm/hydrix_farm.ino` على الـ ESP32 (الخطوات تحت).
2. افتح التطبيق → اضغط **«ربط البلوتوث»** فوق.
3. اختَر الجهاز **Hydrix Farm** من القائمة.
4. لما يبقى مكتوب **«متصل 🟢»** — كل قراءة (رطوبة/حرارة/مطر) بتوصلك من الحساسات فعلًا، وكل زرار ري بيبعت أمر حقيقي للـ ESP32.

### الأوامر اللي التطبيق بيبعتها

| الأمر | المعنى |
|---|---|
| `ON` / `OFF` | تشغيل/إيقاف المضخة (الري اليدوي) |
| `T5` `T10` `T15` `T30` | ري مؤقت بالدقائق — الـ ESP32 يوقف لوحده |
| `SMART_ON` / `SMART_OFF` | تفعيل/إيقاف الري الذكي |
| `TH:40,60` | ضبط حدود الري الذكي من سلايدرز التطبيق |
| `PING` | اختبار الاتصال (يرد `PONG`) |

والـ ESP32 يرد كل ثانيتين بقراءة JSON: `{moist, temp, hum, rain, pump, smart}`.

## 🔧 تركيب كود الـ ESP32 (Arduino IDE)

1. ثبّت **Arduino IDE** وأضف لوحات ESP32 من Boards Manager (ابحث `esp32` by Espressif).
2. ثبّت مكتبة **DHT sensor library** (from Adafruit) ومرافقتها **Adafruit Unified Sensor** من Library Manager.
3. اختر اللوحة (مثلاً ESP32 Dev Module) والبورت واضغط Upload.

### توصيل الأسلاك

| المكوّن | منفذ ESP32 |
|---|---|
| حساس رطوبة التربة (A0) | GPIO 34 |
| حساس المطر (A0) | GPIO 35 |
| DHT22 (البيانات) | GPIO 4 |
| وحدة الريلي (IN) | GPIO 26 |

> ⚠️ المضخة توصل بالريلي وتاخد طاقة منفصلة — متوصلهاش بـ ESP32 مباشرة.
> 🎚️ **المعايرة:** شغّل Serial Monitor، اقرأ قيمة `analogRead` والت ربة جافة (حطها في `SOIL_DRY`) وفي ماء (حطها في `SOIL_WET`).

ميزة مهمة: **الري الذكي شغال على الـ ESP32 نفسه** — يعني لو التطبيق مقفل أو البلوتوث فصل، النظام يسيّق لوحده تحت 40% ويقف عند 60%، وبيمنع الري وقت المطر.

## 🗺️ شاشات التطبيق

| الشاشة | الوصف |
|---|---|
| الترحيب | شعار Hydrix + زر «ابدأ» + توقيع فريق WE |
| لوحة التحكم | حالة التربة، الطقس الفعلي، آخر ري، أنواع الري، **مؤشرات التربة** المحسوبة من بياناتك + شارة «مباشر/تجريبي» |
| الري اليدوي | زرار تشغيل/إيقاف مباشر + إيقاف أمان على الجهاز بعد 20 دقيقة |
| الري المؤقت | 5 / 10 / 15 / 30 دقيقة + عداد تنازلي وإيقاف تلقائي |
| الري الذكي | مفعل/متوقف، **حدود قابلة للضبط** تُرسل للـ ESP32، تنبيهات، عداد توفير محسوب من السجل |
| السجل | رسم بياني لرطوبة 24 ساعة + إحصائيات اليوم + قائمة العمليات + **تصدير CSV** |
| تحليل النبات | كاميرا داخل التطبيق أو صورة من الجهاز + تحليل محلي + تحليل Gemini (يعرف نوع المحصول من الإعدادات) |
| الكاميرا | فيديو حي + زر تصوير دائري + تبديل أمامية/خلفية + المعرض |
| الإعدادات | اسم المزرعة (يظهر في اللوحة وعنوان التطبيق) + نوع المحصول (يُستخدم في تشخيص AI) + التنبيهات + إعادة تهيئة |
| عن المشروع | نبذة + التقنيات + أعضاء الفريق + رقم الإصدار |

> 🎨 التطبيق كله أيقونات SVG مرسومة يدوياً (بدون أي إيموجي) — هوية بصرية موحدة زي التطبيقات التجارية.

### 📊 سجل النشاط (بيانات حقيقية بتتسجل على الجهاز)
- كل عملية ري بتتسجل تلقائياً: مين شغّلها (يدوي/مؤقت/ذكي)، الساعة، والمدة.
- الرطوبة بتتسجل كعينة كل 5 دقائق → رسم بياني لآخر 24 ساعة مع خطي الحدود.
- زرار **تصدير CSV** — افتح الملف في Excel واعمل منه رسوم للتقرير.
- كل حاجة محفوظة في جهازك (localStorage) وتشتغل بدون إنترنت.

### 🔔 التنبيهات
من صفحة الري الذكي فعّل «🔔 التنبيهات» — هيوصلك إشعار على الموبايل حتى لو التطبيق مقفول:
- لما الري الذكي يبدأ أو يقف لوحده (باسم الوضع ونسبة الرطوبة).
- لو الرطوبة هبطت تحت 30% (تحذير عطش — مرة كل ساعة كحد أقصى).

### 🎚️ حدود الري الذكي القابلة للضبط
- غيّر حد بدء الري (25–55%) وحد التوقف (45–75%) من السلايدرز.
- الحدود بتتحفظ على الجهاز وبتتبعت للـ ESP32 تلقائياً بأمر `TH:40,60` أول ما يتصل.
- الـ ESP32 بيأكد الحدود في الـ JSON فالتطبيق والجهاز دايماً متزامنين.

## 🤖 تحليل النبات بالذكاء الاصطناعي (Gemini)

التحليل في التطبيق على مستويين:

1. **تحليل محلي فوري** — يشتغل دايماً بدون إنترنت: يقيس نسبة الخضرة والاصفرار والبقع البنية ويطلع حكم أولي.
2. **تحليل Gemini الذكي** — يتعرف على نوع النبات والمشكلة بالاسم (مثلاً: تبقع أوراق، نقص نيتروجين) ويعطي خطة علاج بالنسبة الثقة.

### تفعيل الـ AI (مرة واحدة، مجاني)
1. افتح [aistudio.google.com/apikey](https://aistudio.google.com/apikey) وسجّل بحساب جوجل.
2. اضغط **Create API key** وانسخ المفتاح.
3. في التطبيق: صوّر/اختر صورة → اضغط **«حلل الصورة بالذكاء الاصطناعي»** → الصق المفتاح → حفظ.
4. المفتاح يتخزن **على جهاز المستخدم فقط** (localStorage) ولا يُرسل لأي مكان غير جوجل.

> 📌 ملاحظة للعرض: الصورة بتتبعت لسيرفر جوجل للتحليل — ذكرها كنقطة أمان في العرض. ولو الإنترنت قطع، التحليل المحلي بيشتغل عادي فالعرض مش هيفشل.

## 💡 الجديد في المشروع (اللي مش بيتكرر)

1. **🌧️ الري التنبؤي بالمطر** — التطبيق يجيب أرصاد منطقتك الفعلية (Open-Meteo)، ولو مطر متوقع يؤجّل الري ويحسب اللترات الموفّرة. يعني النظام بيقرر **قبل** ما التربة تجف، مش بعدها.
2. **🤖 تشخيص النبات بنموذج Gemini** — تصوّر الورقة والـ AI يسمي المشكلة ويعطي خطة علاج بالعربي (وباحتياطي تحليل محلي أوفلاين).
3. **🎙️ تحكم صوتي بالعربي** — «اسقي النبات» / «اقفل الري» من زرار الميكروفون.
4. **💦 عدّاد توفير المياه** — يعرض للجنة أثر المشروع بالأرقام.
5. **🔋 جاهز للتوسع**: بروتوكول JSON في البرنامج مفتوح لإضافة قراءة جهد البطارية/الطاقة الشمسية على نفس السطر.

أفكار تضيفها لو عايز تصدم أكتر: مقارنة صور النبات على مدار أيام (نمو/تراجع)، تنبيهات على موبايل ولي الأمر لو الرطوبة نزلت وهو بره، أو شبكة مزارع تتشارك بياناتها.
